- Risks found:
  - Browsers allow audio only after a click: `connect()` must be called from a button handler (documented in the hook).
  - The resampler is linear interpolation: fine for speech recognition at 16 kHz, not for music; if STT accuracy is poor on some devices this is the first suspect.
  - `getUserMedia` echo cancellation depends on the browser; students using speakers without headphones may feed the AI's voice back (barge-in then fires on its own audio). Headphones should be in the rules text.
  - The vitest `jsdom` environment breaks Node's WebSocket (event class mismatch): the real-backend test file runs in the `node` environment (first line of the file).
